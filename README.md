# The Broncho Intervention Menu

Lafayette Sunnyside Intermediate School's Tier 1 behavior intervention website. Plain HTML, CSS, and JavaScript; no build step.

| Page | What it does |
| --- | --- |
| `index.html` | Home: what Tier 1 is, intervention vs. consequence, the three problems the site addresses, the full Sunnyside Behavior Intervention Matrix, behavior functions, and log type guidance. |
| `menu.html` | Teachers check the behaviors they see (each matrix behavior has detailed "looks like" options), confirm the likely function, and get ranked, research-cited Tier 1 interventions. Chosen interventions go into a plan. Level 3/4 choices show referral guidance. |
| `log.html` | PowerSchool Log Builder in three tabs. **Format it for me** walks through 3 steps (What happened, What you did, Family & next step) with a live PowerSchool preview: Title plus a one-paragraph Log Entry with no date or labels. **Strengthen my own** rewrites a teacher's entry and checks it against required elements. **Student records** is the Proof of Intervention record and the MTSS Request for Support packet. Every guidance message names its source. Enforces the Sunnyside Tier 1 timeline: at least 3 Tier 1 interventions, each tried for 2 to 3 weeks, before an MTSS referral. **Strengthen my own** sorts each sentence into behavior, intervention, student response, parent contact, or consequence, rewrites it in objective language, fills the date and setting, and blocks saving or copying when the Log Type does not match the entry. Teachers can add their own researched intervention (PBIS World), matched to the function of the behavior. Logs are saved on the device, with a backup file to save and restore. |
| `logs.html` | Student Logs: every saved entry on the device, filterable by student, log type, level, behavior, location, intervention, response, parent contact, date, and text, with sortable columns, CSV export, print, and backup/restore. |
| `tools.html` | 4 C's Classroom Audit (Climate, Communication, Curriculum, Culture: rate 24 practices, see likely behaviors and next steps); Essential Behaviors (prioritize essential academic and social behaviors and print behavior lesson plans, organized around Hannigan et al., 2020, *Behavior Solutions*); teacher tips (with a printable desk card); HEART posters (editable school-wide matrix, values poster, 8 animated Broncho character modeling posters, 5 student reminder posters); free incentives with a reward menu, notes home, Mystery Motivator chart, and punch cards; class jobs (chart, cards, applications, rotation log); class agreement and student behavior contract templates; buddy-classroom visiting passes with reflection sheets. Plus tools from the ONC BOCES Tier 1 toolkit: ABC behavior statement organizer (ranks the likely function and links to matched interventions), Tier 1 classroom self-check (22 practices, 5 foundations), printable Daily Behavior Report (recommended replacement behaviors for each struggle, with Broncho Bucks) with daily tracking, a progress graph, and decision rules, and a behavior checklist maker for student self-monitoring. |
| `supports.html` | ML & SPED supports. **Multilingual Learners**: check language before calling it defiance, visuals, sentence frames, wait time, structured partner talk, pre-taught vocabulary, family contact through qualified interpreters. **IEP & 504**: follow the plan and BIP first, visual schedules, First/Then, break cards, choice, self-monitoring, praise, and IDEA documentation and removal protections. **Printables**: request cards (English/Spanish), partner talk frames, First/Then board, break cards, visual schedule. Every support is cited. |
| `parent.html` | Parent Contact: before/during/after tips, research, a script builder (concern call, good news, progress follow-up, voicemail, email) matched to each matrix behavior with plain-language interventions and ideas for home, "say this instead" phrases, and help for difficult calls. Nothing entered is saved. |
| `mtss.html` | Sunnyside MTSS Team: team members and roles, meeting details, and how to bring a student to the team. Fill in names, emails, and meeting details in `js/mtss-data.js`. |
| `research.html` | Every reference in APA format, with the interventions each one supports. |

Content lives in `js/data.js` (behaviors, interventions, citations) and `js/tools-data.js` (ABC organizer, self-check, report items), and `js/tools-data2.js` (tips, posters, jobs, incentives, replacement behaviors). Plans and saved logs are stored only in the teacher's browser (`localStorage`); use initials or student numbers.
